# Manon Derydt

Full-stack developer based in Paris. I design, build and ship SaaS products end to end, from the data model to production, and I run LLMs in production.

**Stack I use every day:** TypeScript, React, Next.js, Node.js, NestJS, Tailwind CSS · PostgreSQL, Supabase (Row Level Security, Edge Functions), Drizzle, TypeORM · Stripe (Checkout, Connect, webhooks) · Python, FastAPI · Claude and GPT APIs · Vitest, Jest, GitHub Actions, Docker

## Products in production

- **Raisup** ([raisup.fr](https://www.raisup.fr)): SaaS that turns a startup's numbers into a full fundraising file (score, valuation, business plan, investor deck). Four isolated user spaces, deterministic scoring engine, LLM pipeline with retry and output validation, Stripe payments.
- **White-label B2B SaaS, regulated sector:** multi-tenant platform where each partner firm gets its own branded space, with per-tenant isolation enforced in PostgreSQL, document generation, scheduled reminders and partner commissions through Stripe Connect.

The source code of these products is private and available on request.
